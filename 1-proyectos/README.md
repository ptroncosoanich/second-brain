# 1-proyectos

Proyectos activos: esfuerzos con objetivo claro y deadline. Una carpeta por proyecto (`<slug>/`), creada por `/para-init`, `/cierre-dia` o a mano desde `3-recursos/plantillas/proyecto.md`. Cada proyecto se lista en el portafolio de `perfil.md`.

Cuando un proyecto termina, su carpeta se mueve completa a `4-archivo/`.
