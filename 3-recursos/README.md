# 3-recursos

Material de referencia transversal: no es accionable por sí solo, pero sirve a muchos proyectos y áreas.

| Carpeta / archivo | Qué es |
|---|---|
| `plantillas/` | Plantillas de `AGENTS.md` para proyectos y áreas nuevos — edítalas para cambiar la forma de todo lo que se cree |
| `frameworks/` | Métodos de referencia (PARA, y los que agregues: JTBD, RICE…) |
| `ideas-proyectos/` | Ideas para proyectos futuros (`/idea`, `/capturar "idea: ..."`) |
| `queries/` | Queries de BigQuery reutilizables (`/datos`, `/amplitude`) |
| `inbox.md` | Lo que no se pudo clasificar con certeza |
| `inbox-reuniones/`, `inbox-chat/` | Reuniones e hilos sin routing claro (los deja `/cierre-dia`) |
| `chat-spaces.md` | Índice de spaces de Chat que usa `/cierre-dia` |
