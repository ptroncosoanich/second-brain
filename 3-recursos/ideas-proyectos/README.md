# Ideas para proyectos futuros

> El "Someday/Maybe" de PARA: ideas de proyectos que **todavía no son compromisos** pero vale la pena no perder.

## Qué va aquí

- Features o productos que podrían convertirse en proyecto algún día.
- Hipótesis a explorar cuando haya espacio.
- Oportunidades cross-equipo sin deadline ni dueño.
- Propuestas que quieres madurar antes de presentarlas.

## Qué NO va aquí

- Compromisos con deadline → `1-proyectos/<slug>/`
- Pendientes accionables → `pendientes.md` del proyecto o área
- Material de referencia general → otras carpetas de `3-recursos/`

## Estructura

```
ideas-proyectos/
├── README.md       # este archivo
├── inbox.md        # capturas rápidas, una línea por idea (/capturar "idea: ...")
└── <slug>.md       # una idea con forma, con plantilla (/idea "<concepto>")
```

## Ciclo de vida

1. **Captura** → `inbox.md` (una línea) o archivo dedicado con `/idea`.
2. **Maduración** → enriquecer con contexto, evidencias y conversaciones.
3. **Promoción** → cuando hay deadline o entregable: crear `1-proyectos/<slug>/` desde `3-recursos/plantillas/proyecto.md` con el contenido de la idea, y agregarlo al portafolio de `perfil.md`.
4. **Descarte** → mover a `4-archivo/ideas-descartadas/` con una línea de por qué.

**Madurez** (campo del archivo): `semilla` · `explorando` · `lista-para-promover` · `descartada`.
